# 04 — Productized Service Offerings

A tiny team cannot survive on open-ended time-and-materials consulting — every project
becomes a custom snowflake that demands specialists. **Productization is what makes the
A-Team model economically real.** Because configuration is templated and automated, we
can sell fixed-scope, fixed-price "editions" with predictable delivery.

## The packaging model

### Tier 0 — "Odoo Launchpad" (fixed price, ~2–3 weeks)
- One vertical template, lightly tailored. Core modules only (e.g. CRM, Sales, Invoicing,
  Inventory or the vertical's essentials).
- Standard data import (templated spreadsheets), 1 training session, 2 weeks support.
- **No custom development.** If they need custom, they're not a Tier 0 client.
- Delivered almost entirely by the Delivery Specialist + platform. The volume product.

### Tier 1 — "Odoo Business" (fixed price, ~4–8 weeks)
- Full vertical template + moderate tailoring via Studio.
- Multi-module (add Manufacturing / Project / Accounting / eCommerce as needed).
- Real data migration, integrations from a pre-built connector catalog, role-based training.
- Small custom items allowed from a fixed "customization credits" pool.

### Tier 2 — "Odoo Enterprise / Bespoke" (scoped per project)
- Genuinely complex: heavy custom modules, novel integrations, multi-entity/multi-country.
- Priced per scope; may temporarily staff up beyond the core team.
- The 20% that justifies the Principal's direct involvement.

### Recurring — "TechNext Care" (monthly subscription)
- AI-first support desk + human escalation, hosting management, version upgrades,
  continuous improvement hours. **The annuity that smooths cash flow** and is mostly
  delivered by the automation platform.

## Why this works with a small team

| Lever | Effect |
| --- | --- |
| Fixed scope | No scope creep eating unpriced hours |
| Templated config | Delivery time is predictable and short |
| Tiered AI support | Recurring revenue without linear headcount |
| Custom isolated to Tier 2 | The one expensive activity is contained and priced |
| Productized = repeatable sales | The SE sells a known thing, not a custom estimate each time |

## Add-on catalog (cross-sell, all pre-built)

- Connector catalog: payment gateways, shipping carriers, local tax/e-invoicing, BI tools.
- Industry add-on modules from the reusable catalog.
- Data migration packs per source system (QuickBooks, Excel, legacy ERP).
- Training packages and AI-generated documentation bundles.

## Pricing philosophy

- Price on **value and outcome**, not hours — the automation is *your* margin, not a
  discount you pass through.
- Publish Tier 0/1 starting prices to pre-qualify and shorten the sales cycle.
- Anchor every deal toward **TechNext Care** for predictable recurring revenue.
