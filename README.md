## TL;DR

- **From 8 roles to 3–4 people + 1 automation platform.** A Solutions Engineer,
  a Senior Odoo Engineer, and a Delivery Specialist — amplified by an AI/automation
  layer — replace the account manager / business analyst / functional consultant /
  project manager / dev lead / developer / frontend / tester pyramid.
- **Automation is the "fifth team member."** Demos provision themselves, discovery
  calls auto-generate scope documents, configuration is shipped as reusable
  vertical templates, tests are generated, support answers itself first.
- **Productize the service.** Fixed-scope, fixed-price "editions" replace
  open-ended time-and-materials, which is what makes a tiny team profitable.
- **Dogfood Odoo.** TechNext runs its own sales, delivery, and support on Odoo —
  every internal process is a live reference implementation.

> Assumptions are stated explicitly in
> [`docs/01-executive-summary.md`](docs/01-executive-summary.md). Tune the headcount
> and revenue figures to TechNext's actual numbers — the model scales linearly.
